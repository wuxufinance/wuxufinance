1. 原首页是依赖JavaScript的登录入口，公开课程没有独立HTML。现已提供64个有完整静态内容的正式页面：公开首页、课程总览、3个系列目录、43讲公开介绍、专题目录与6篇专题、工具目录与7个工具、关于页面。受限课程仅公开介绍和知识目录，完整正文继续由原系统验证访问。
2. 三个课程系列分别为金融经济学基础总课程（40/40讲）、专业个人投资者与长期财富管理实战课程（2/30讲）、全球宏观投资研究实战课程（1/30讲）。系列页包含定位、适合人群、学习目标、学习顺序与完整规划。未发布讲次标记为规划，不制造可访问的空正文。
3. 每讲介绍使用独立路径，连接所属目录、已发布的上一讲与下一讲、相关课程和专题；完整知识单元链接进入原有受控学习空间。原正式域名下 `/#/course/...`、目录、实验、复习、进度及开通片段链接兼容转入 `/learn/`，管理入口路径已适配。
4. 64页具有独立标题与简介、单一主标题、连续的标题层级、准确的canonical、中文语言和移动视口、Open Graph与分享图片。增加网站、面包屑及符合页面内容的文章或工具结构化数据；没有虚构评分、资历或收益记录。
5. 生成只含64个正式公开页面的`sitemap.xml`，不包含登录、管理、私人数据或片段地址。学习、管理和404页声明noindex。保留用户原有Google验证文件，并为当前Search Console属性增加真实验证标记。
6. 新专题使用首次发布的真实日期2026-11-25；不把课程原始日期批量改为本次发布日，也不编造作者个人资历。真实历史背景、假设家庭、模拟组合和工具默认参数分别说明。
7. 公开页面采用系统字体、本地样式和构建时生成的MathML；计算模型按需加载。首页HTML为14,417字节，公开CSS为10,328字节，1200×630分享PNG为35,109字节。表格和长公式在容器内滚动；手机采用单栏。未声称获得Core Web Vitals现场分数。

## Search Console 实际状态与尚未完成事项

- 正式URL前缀属性已通过HTML标记验证。首页、债券基金专题和财富管理第2讲公开介绍的Google手机实时测试显示“URL is available to Google”，抓取成功、允许索引；专题与课程介绍检测到有效面包屑。索引库检查仍显示这些新页面未收录，不能表述为已实现排名或流量。
- 已提交上述准确的`sitemap.xml`，并在确认线上200及XML有效后重新提交一次。Google接受提交，但地图处理仍显示“Couldn't fetch / Sitemap could not be read”，发现页面数为0。本次未能消除Google端的地图读取失败；请在该正式属性的Sitemaps页面复查处理结果，必要时使用同一准确地址重新提交。
- GitHub仓库About的Website字段仍指向旧用户名。代码连接可发布文件，但没有仓库简介编辑接口；当前GitHub浏览器未登录。该字段需要在仓库About右侧齿轮内改为正式网址。站内canonical、地图、链接和部署地址已全部使用新用户名。
- GitHub项目仓库只控制`/wuxufinance/`，无法在当前仓库为域名根目录安装有效robots规则。根`/robots.txt`本次返回404，项目内robots文件为位置明确标注的参考文件；受限内容依靠服务端权限和页面noindex保护。说明见[Google robots规范](https://developers.google.com/crawling/docs/robots-txt/robots-txt-spec)。
- 更名前域名的服务器301不受当前仓库控制，不能声称已修复旧域名跳转。已兼容当前正式域名下原有有效的片段书签；旧域名书签需改存正式地址。
