# 戊戌 · 金融知识体系

中文互动学习平台。网页由 GitHub Pages 托管，课程与账号数据由 Supabase 提供。支持人员审核、浏览器授权、账号进度同步、服务器评分、课程草稿和版本管理。

## 首次使用

管理员邮箱和一次性开通链接通过独立的受控配置提供，不放在这个公开仓库。完成首次开通后，访问网站并登录，选择“管理后台”。学员账号由管理员开通；学员首次使用的浏览器需要管理员批准。

管理员身份尚未配置时，网站会提供登录界面，但不会向未授权访问者发送课程正文。公开源码不包含课程内容、学习者数据、后端密钥或管理员开通凭据。

## 课程更新

管理后台的“课程管理”支持新增或编辑课程、知识单元、公式、生活案例和测试题。取消发布勾选可保存草稿，勾选后发布。每次保存建立新版本，学员刷新后会载入新内容；测试成绩按课程版本记录。编号用于关联历史阅读与错题，请保留原单元、题目的稳定编号。

课程正文在数据库中更新，不需要修改 GitHub 源码。公开仓库里的 `dist/courses.js` 只是接收授权课程的加载器。

当前已发布第 1–40 讲，共 600 个知识单元、119 个案例与 460 道测试题。第 11–29 讲按原课程目录整理为网页学习版，涵盖银行与市场、宏观经济、风险管理、衍生品、公司金融、行为金融、量化、基金、投行、监管及全球投资。原目录中的复习与进阶讲次分别保留，后续可继续新增课程。

## 人员与设备

每个账号有独立的学习记录。管理员可暂停账号，设置 1 至 10 个浏览器授权上限，并批准或撤销某个浏览器。授权按浏览器保存的随机凭据管理，不代表不可复制的硬件绑定。已下载的内容无法远程收回；撤销后服务端会拒绝后续受保护请求。

管理员可查看理解标记、练习成绩和最近学习时间，不查看笔记正文。阅读标记由学员自行确认；练习使用服务端评分，并不作为防作弊考试系统。

## 部署

1. GitHub Pages 的发布来源为 `gh-pages` 分支根目录。
2. 主分支更新后，工作流自动验证代码和公开文件边界，只使用读取权限。界面源码需要发布时，将通过检查的 `dist/` 同步到 `gh-pages`；课程正文从后台更新，不需要触发网页重新发布。
3. Edge API 的源码在 `server/`，函数名 `finance-api`。函数在内部验证 Supabase Auth 用户、数据库会话、账号状态和浏览器凭据；网关的 `verify_jwt=false` 是为首次开通接口及现代发布密钥使用，受保护操作仍全部在函数内部认证。
4. `server/schema.sql` 是数据库初始结构。所有表对浏览器角色拒绝访问，RPC 只授予后端 service role。不要把后端密钥放进 `dist/config.js`。

`dist/config.js` 只包含可公开的 Supabase API 地址和 publishable key。后端 service role key 仅从 Edge Function 的环境读取。

## 课程排版与发布检查

正文支持段落、列表、强调、表格和 LaTeX 公式；计算工具以 `<p>互动工具：已注册工具编号</p>` 引用。后台编辑保留原 HTML 结构，并提供与学员页面一致的预览。未知工具、生成占位、错列表格及无法排版的公式会阻止保存。

更新依赖后先运行 `npm ci`，再运行 `npm test`。对私有课程导出运行 `npm run audit:courses -- /absolute/private-export.json`，检查所有知识单元和案例。批量结构修复可用 `node scripts/repair-curriculum.mjs /private/before.json /private/after.json`，随后核对正文与数字、预览并通过完整审计后再写入数据库。不要将这些导出文件放入公开仓库。

公式引擎固定为 KaTeX 0.19.1，随站点提供本地模块与许可证，使用浏览器原生 MathML 显示，不依赖外部 CDN。纯排版修复保留学习版本与题目，避免重置练习记录；修复前快照保存在私有数据库中。

第 32–35 讲按完整原课整理，新增 47 个互动计算器，并保留参数快照与答案解析。课程原稿与发布数据保存在受权限保护的后端，公开仓库只包含程序。

第 36–40 讲新增 135 个知识单元、25 个案例、160 道原课测试题（第40讲40题），64个编号计算器，另含经营驾驶舱与建设自评。原始SVG经白名单清洗后在本地显示；表格内公式只渲染一次。模拟结果采用明确假设，蒙特卡洛使用可复现种子并展示抽样误差。
